# radio-fx

内蔵プリセットの **2 つめ・3 つめ（SPRING / PIXIE の位置）を、ラジオ系 FX 2 つで上書きする**パック。
プリセット定義は teenage engineering 公式 `broken radio` パックのものを使用（個人利用）。

## スロット割り当て

オレンジボタンは **1 番目がクリーン**なので、FX スロット N は N+1 番目のポジションになる。

| オレンジボタン | JSON の `pos` | 中身 | 状態 |
| --- | --- | --- | --- |
| 1 番目 | — | クリーン（エフェクトなし） | 内蔵のまま |
| 2 番目 | `pos: 0` | ECHO | 内蔵のまま ✅確認済み |
| 3 番目 | `pos: 1` | **AM TUNER** | ★上書き |
| 4 番目 | `pos: 2` | **WALKIE TALKIE** | ★上書き |
| 5 番目 | `pos: 3` | ROBOT | 内蔵のまま ✅確認済み |

## 各プリセット

### AM TUNER（`pos: 1`）

```
SSB(frequency -500Hz) → DIST(amount 5.0, mix 0.2) → SAMPLE
handle → SSB.frequency +1000  （選局。押すと音程が大きくずれる）
shake  → SSB.frequency +200   （微揺れ）
```

周波数シフトで「局を探している」感じを出す。ハンドルの効きが一番分かりやすいプリセット。

### WALKIE TALKIE（`pos: 2`）

```
HIGHPASS(0.1) → LOWPASS(0.4) → DIST(amount 15.0, mix 0.5) → SAMPLE
handle → LOWPASS.cutoff +0.5  （チューニングダイヤル。押すと抜けが良くなる）
shake  → DIST.mix       +0.5  （ノイズ増）
```

ハイパス+ローパスの 2 段でバンドパスを作り、歪ませてトランシーバーの音にする。
声のキャラ変えとして実用的。

## ✅ 部分差し替えは成立する（2026-08-29 実機確認）

`presets` に書かなかったスロットは**工場出荷プリセットのまま残る**。
公式ドキュメントに記載がなかったため、このパックで検証した。結果は `docs/config-json.md` に反映済み。

## 手順

```bash
tools/deploy.sh packs/radio-fx
```

## 確認すること

オレンジボタンを一周させ、各ポジションで**ハンドルを押しながら声を入れて**判定する。

| ポジション | 期待 | 結果 |
| --- | --- | --- |
| 1 番目 | クリーン | |
| 2 番目 | ECHO（内蔵） | ✅ そのまま鳴った |
| 3 番目 | **AM TUNER**（ハンドルで音程が大きくずれる） | |
| 4 番目 | **WALKIE TALKIE**（バンドパス+歪み、ハンドルで抜けが変わる） | |
| 5 番目 | ROBOT（内蔵） | ✅ そのまま鳴った |
