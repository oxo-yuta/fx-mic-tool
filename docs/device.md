# EP–2350 fx-mic デバイス仕様

出典: [公式ユーザーガイド ver 1.1.1](https://teenage.engineering/guides/ep-2350) / 同梱 `factory/readme.pdf` / [ダウンロードページ](https://teenage.engineering/downloads/ep-2350)

## 1. 概要

teenage engineering EP–2350 fx-mic は、エフェクト内蔵のハンドヘルド・パフォーマンスマイク。

- 内蔵 FX プリセット 4 スロット + クリーン（エフェクトなし）
- サンプル 4 スロット（**約 1 MB** のサンプルストレージ）
- ハンドル（レバー）位置・シェイク（振り）・LFO でパラメータをリアルタイム変調
- ファームウェアは Raspberry Pi PICO SDK + MicroPython ベース（`factory/readme.pdf` のライセンス表記より）

### 技術仕様

| 項目 | 値 |
| --- | --- |
| 寸法 | 88 × 56 × 16 mm |
| 重量 | 100 g |
| ステレオライン出力 SNR | 98 dBA |
| 最大出力レベル | 8 dBu / 2 VRMS |
| サンプルストレージ | 約 1 MB（FAT フォーマット） |
| 電源 | 単4 電池 × 2 または USB-C |

> **⚠️ 出力レベルの注意**
> 2 VRMS はヘッドホン直挿しには過大。fx-mic は K.O.II / MEDIEVAL / RIDDIM やミキサーへの接続を想定している。ヘッドホンに直結しないこと。音量は下蓋の中にある丸いポテンショメータで調整する（色の表記が資料間で揺れている: 公式ガイド=オレンジ、同梱 readme=緑）。

## 2. 操作系

| 操作子 | 役割 |
| --- | --- |
| ハンドル（レバー） | 押すと電源 ON。**押している間だけマイクが有効**。押し込み量 0〜100% がエフェクトパラメータを変調 |
| オレンジボタン | エフェクトプリセット選択（クリーン + 4 スロット） |
| 白ボタン | サンプルスロット選択（1〜4） |
| グレーボタン | 選択中のサンプルを再生 |
| ポテンショメータ（下蓋内） | 出力音量 |
| 小ボタン（USB-C ポート上） | 短押し: 電源 OFF / ダブルクリック（ハンドル保持中）: ファームウェア更新モード |
| 本体を振る（シェイク） | プリセット依存でエフェクトを一時変調 |

> **📌 ボタン名称の資料間の揺れ**
> 同梱 `factory/readme.pdf`（旧版）は「緑ボタン = サンプル選択 / 白ボタン = 再生」と記載。公式ガイド 1.1.1 は「白 = 選択 / グレー = 再生」。物理ボタンは同一で、**本リポジトリでは公式ガイド 1.1.1 の呼称（オレンジ / 白 / グレー）に統一**する。

### 工場出荷時のプリセット・サンプル

- エフェクトプリセット: `ECHO` / `SPRING` / `PIXIE` / `ROBOT`（+ クリーン）
- サンプル: `horn`（ホーン） / `applause`（拍手） / `ringside bell`（ゴング） / `censor beep`（ピー音。fx-mic を一時ミュートする放送禁止用語対策）

## 3. 電源まわりの挙動

- 電池: ハンドルを離してから **5 分でパワーセーブ、20 分で電源 OFF**
- 電池電圧が低すぎると LED が点滅して起動しない
- 保管時は電池を抜く
- USB 給電中はケーブルを抜くまで電源が入り続ける。**USB 給電中は電池を使わない／電池は充電されない**

## 4. USB マスストレージ（fx-mic disk）

1. 下蓋を外して USB-C ケーブルで PC に接続
2. **ハンドルを押して電源を入れる**（電源 OFF だとディスクが出てこない）
3. ディスクがマウントされる
4. ルートに `1.wav`〜`4.wav` と `config.json` を置く
5. ディスクを**取り出し（eject）**すると fx-mic が再起動して新しい設定を読み込む

### ⚠️ ボリューム名は `fx-mic disk` とは限らない（実機で確認）

公式ガイドは「`fx-mic disk` というディスクが現れる」と書いているが、**実機では `NO NAME` でマウントされた**
（一度 FAT で再フォーマットするとラベルが失われるため。動作上の問題はない）。

ボリューム名で判別せず、`diskutil` の **Device / Media Name** で確認するのが確実:

```bash
diskutil info /Volumes/NO\ NAME | grep -i 'device / media name'
#   Device / Media Name:       EP-2350 DRIVE     ← これが出れば fx-mic
```

`NO NAME` は普通の USB メモリでもごく普通に付く名前で、転送時には既存の `*.wav` / `config.json` を
削除するため、**行き先の取り違えは実害がある**。`tools/deploy.sh` はこの `diskutil` 判定で自動検出し、
EP-2350 と確認できないディスクには `-y`（無確認実行）を拒否する。

> OS 1.0.5 以降、eject でサンプルと設定が再読み込みされる。それ以前は手動での電源 OFF/ON が必要。

### 「空きがない」と言われる場合

ディスクが空に見えるのに「not enough disk space」と出るときは、`fx-mic disk` を **FAT で再フォーマット**する（macOS: 右クリック → ディスクを消去 / Windows: フォーマット）。

## 5. ファームウェア更新

最新は **OS 1.1.1（2026-08-25）**。ファイルは `.uf2`（zip 配布）。

| OS | 日付 | 主な変更 |
| --- | --- | --- |
| 1.1.1 | 2026-08-25 | 起動時のクリックノイズ改善 |
| 1.0.8 | 2025-12-05 | ノイズフロアのフラッター除去 |
| 1.0.7 | 2025-11-25 | プリセット切替時のリバーブのクリック除去 / サンプルループのグリッチ修正 / **1.0.5 からの JSON ローディング退行を修正** / **JSON パースエラーをいくつか修正** / スリープ後に工場サンプルが読み込まれる不具合を修正 |
| 1.0.5 | 2025-11-04 | 更新モードのドライブ名・VID/PID 修正 / **eject でサンプルと設定を再読み込み** / マイク音量をサンプル再生に対して下げた |

> **📌 カスタマイズ前に必ず OS を最新にする**
> 1.0.7 で JSON パースの不具合が複数修正されている。古い OS では「JSON が正しいのに読めない」事象が起こりうるため、config.json の挙動を検証する前提として OS 1.1.1 にしておくこと。

### 更新手順

1. 下蓋を外して USB-C 接続
2. **ハンドルを押したまま**、USB ポート上の小ボタンをダブルクリック
3. `FX MIC BOOT` ドライブが出る（`INDEX.HTM` と `INFO_UF2.TXT` が入っている）
4. `.uf2` ファイルをドラッグ&ドロップ
5. 転送完了して自動再起動（白 LED 点灯）するまで**ハンドルを離さない**

## 6. リカバリ（config.json を壊して起動しなくなったとき）

JSON の構文が壊れていると **fx-mic は起動しない**。復旧方法:

- **白 + グレーボタンを押しながら起動**すると config を読まずに立ち上がり、ディスクにアクセスして修正できる
  （同梱 readme.pdf 旧版の表記では「緑 + 白」。同じ 2 つのボタンを指す）

このリスクがあるため、**転送前に必ず `tools/validate.py` を通す**こと（`docs/workflow.md`）。
