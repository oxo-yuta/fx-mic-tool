 fx-mic is a standalone handheld performance microphone with built in fx, 4 on-board samples and a parameter modulation lever. it's not hi-fi, but it’s definitely not boring! hook it up to your sound system or straight into k.o.ii. 
 fx-mic features 1 mb of sample storage, more than any other microphone. use it to store your own sounds, then trigger them with the dedicated sample trigger button.

 ((2)) 
 power on 
 remove the two front covers and insert 2 x AAA batteries. 
 you can also power fx-mic with a usb-c cable. 
 pressing the handle will power fx-mic on. it will light up to let you know it is on. 
 2.1 
 battery 
 when powered over usb-c EP–2350 fx-mic will stay powered until you pull the cable. 
 the batteries will not be used if powered over usb. 
 the batteries will not be charged over usb-c. 
 5 minutes after releasing the handle EP–2350 will go into power saving mode. 
 20 minutes after releasing the handle EP–2350 will turn off. 
 if the battery voltage is too low or if they run out an LED will blink and EP–2350 will not turn on. 
 remove the batteries when storing EP–2350. 
 ((3)) 
 connecting fx-mic 
 loud sound levels leads to hearing loss.  
 FX-MIC is designed to connect
to koii or an audio mixer, not directly to headphones. 
 the maximum output is 2 VRMS. this can be very loud when connected directly to
headphones. 
 under the lid there is a round orange potentiometer. turn it to adjust the volume. 
 ((4)) 
 adding fx and samples 
 the position of the handle can be used to change the amount of an effect. 
 shaking EP–2350 fx-mic can temporarily modify the sound of an effect, this is preset dependent. 
 the orange button selects between no effect and the 4 effect preset slots.  
 the built-in effect presets are: ECHO, SPRING, PIXIE, ROBOT 
 the white button selects between the 4 sample slots. 
 the built-in samples are: horn, applause, ringside bell, censor beep (temporarily mutes fx-mic, for foul language emergencies) 
 the grey button plays the selected sample. 
 ((5)) 
 updating the firmware 
 you will need a firmware file. new firmware files are available on the downloads page here . 
 remove the lower lid and attach a usb-c cable to your computer. 
 hold the handle and double click the small button above the usb port. 
 a disk called ‘FX-MIC BOOT’ will appear on your computer with the files INDEX.HTM and INFO_UF2.TXT, drag and drop the firmware file to this disk
and wait until transferred and EP–2350 fx-mic restarts. do not release the handle until the update has been completed and EP–2350 restarts. 
 ((6)) 
 changing the samples and fx 
 remove the lower lid and attach a usb-c cable between fx-mic and your computer. make sure fx-mic is powered on by pushing the handle. 
 a disk called ‘fx-mic disk’ will appear on your computer.  
 here you may place your samples, named 1.wav, 2.wav, 3.wav and 4.wav as well as a config.json file.
only wav samples are allowed and The samples can be mono or stereo, 8/16/24-bit or 32-bit floating point, with a frequency up to 96 kHz. total storage is 1 mb 
 eject ‘fx-mic disk’ on your computer. fx-mic will then restart and load the new sounds.
for more advanced sample features go to chapter 7.4. 
 ((7)) 
 customising fx-mic 
 the heart of your device is a file named config.json. by editing this file, you can completely redesign how the unit sounds, how the effects behave, and how you interact with the audio using the handle, motion, and automation. 
 7.1 
 installing a new config file 
 remove the lower lid and attach a usb-c cable between fx-mic and your computer. make sure fx-mic is powered on by pushing the handle. 
 a disk called ‘fx-mic disk’ will appear on your computer.  
 place a config.json file into the root folder. 
 eject ‘fx-mic disk’ on your computer. fx-mic will then restart and load the config file. 
 7.2 
 the golden rules 
 json is a strict text format. if you break the syntax, the unit will not start. 
 quotes are mandatory, every text element must be inside double quotes. 
 watch your commas, every line in a list must end with a comma, except the last one. this is the #1 cause of errors. 
 mind case sensitivity, always use uppercase for effect names. 
 messed up? if you happen to break the json file for some reason and the device freezes, don’t panic. simply connect to a computer and hold the white + grey  buttons during startup to access and fix the file.
 7.3 
 file anatomy 
 the file is divided into three main sections inside the root brackets { }: 
 1. name: the name of your pack. 
 2. samples: the list of audio files (or omit this to use internal sounds). 
 3. presets: the effects chains. 
 basic skeleton: 
 .json 
 {
 "name": "MY PACK NAME", 
 "samples": [ ... ],
 "presets": [ ... ]
} 
 7.4 
 samples 
 requirements: format: wav only. mono or stereo.
 bit depth: 8/16/24-bit or 32-bit float.
 max frequency: 96 khz.
 total size limit: approx. 1 mb.
 playmodes: "oneshot": plays the full file once when triggered.
 "hold": plays only while the button is held down.
 "startstop": press to start loop, press again to stop.
 syntax: 
 .json 
 { "file": "drum.wav", "playmode": "oneshot" } 
 7.5 
 using the built in samples 
 if you want to use the 4 factory built-in sounds instead of your own wav files, follow these rules: 
 1. remove the samples section: delete the entire 
"samples": [ ... ] 
block from your json file. 
 2. include the sample block: you must still include  { "effect": "SAMPLE" } inside your preset chain (see section 4), otherwise no sound will be generated. 
 3. signal flow and fx: the position of the sample block in the list matters. 
 4. to apply fx: place the sample block before the effects you want to affect the sample.
to keep it dry (no fx): place the sample block at the very end of the list. 
 7.6 
 presets and effects 
 the presets list defines the 4 slots (orange button). each preset contains a chain of effects (list) and modulation rules.
effects are processed based on their order in the list. 
 syntax: 
 .json 
 "list": [  
  { "effect": "DIST", "amount": 10.0 },  
  { "effect": "REVERB", "time": 0.5 },
  { "effect": "SAMPLE" } 
] 
 you can place fx on different slots on fx-mic with pos; the preset slot number (0, 1, 2, 3).
in this example the first file will play on the the first sample slot ‘0’ and the second fill be placed on the last sample slot ‘3’. 
 .json 
 "samples": [
     { "file": "A.wav","playmode": "oneshot" },
     { "pos": 3, "file": "D.wav","playmode": "oneshot" }
   ] 
 optionally we suggest you add the following fields:
 name: (optional) a human-readable name for your preset.
 comment: (optional) notes on how the preset works.

 7.8 
 modulation 
 you can control parameters live using the handle, shaking fx-mic, or an with an lfo (low frequency oscillator). modulation blocks (handle, shake, lfo) are placed after the effect list. 
 to target a parameter you must tell the unit which row in your effect list to change.
 row : the index of the effect (starts at 0).
 param : the exact parameter name (e.g., "time", "cutoff").
 depth : how much to change the value.
the handle can control an effect based on it’s position (0% to 100%).
 values can be either:
 positive (e.g., 10.0): pushing handle increases value.
 negative (e.g., -1.0): pushing handle decreases value (inverse control).
 syntax: 
 .json 
 "handle": { "row": 0, "param": "cutoff", "depth": 0.8 } 
 shake triggers changes when the unit is physically shaken. great for "glitch" effects or temporary reverb splashes. 
 syntax: 
 .json 
 "shake": { "row": 1, "param": "mix", "depth": 1.0 } 
 lfo automatically cycles a parameter value over time. 
 syntax: 
 .json 
 "lfo": {
  "row": 0,
  "param": "pitch",
  "depth": 0.1,
  "shape": "sine",
  "speed": 4.0,
  "phase": 0
} 
 its parameters include:
 shape: sine (smooth), square (on/off), sawtooth (ramp), random (chaos).
 speed: how fast the lfo cycles.
 7.9 
 advanced modulation 
 instead of controlling an effect, the handle can control the lfo itself. this allows you to speed up a wobble or increase a vibrato by pushing the handle. 
 use "target": "lfo" instead of "row". 
 syntax: 
 .json 
 "lfo": {
  "row": 0,
  "param": "balance",
  "shape": "square",
  "speed": 2.0
 },
  "handle": {
  "target": "lfo",
  "param": "speed",
  "depth": 15.0
 } 
 in this example: the sound chops back and forth (lfo). pushing the handle makes the chopping faster. 
 7.10 
 bus routing 
 by default, effects are serial (one after another). use BUS to create parallel paths (e.g., keeping the dry signal clean while distorting a copy). 
 add "BUS": 1 or "BUS": 2 to an effect line to route audio specifically. 
 7.11 
 example preset 
 here is a complete "broken radio" style preset based on real examples. 
 syntax: 
 .json 
 {  "pos": 0,
  "name": "BAD RECEPTION",
  "comment": "static noise that clears up when handle is pushed",
  "list": [
  { "effect": "DIST", "amount": 10.0, "mix": 0.5 },
  { "effect": "LOWPASS", "cutoff": 0.2 },
  { "effect": "SAMPLE" }
 ],
"handle": {
  "row": 1,
  "param": "cutoff",
  "depth": 0.8
 },
"shake": {
  "row": 0,
  "param": "mix",
  "depth": 0.5
 },
"trigger": { "row": 2 }
} 
 audio goes through distortion (row 0) -> lowpass filter (row 1) -> sample out (row 2).
 the lowpass filter starts closed (0.2), making it sound muffled.
 handle: pushing the handle adds 0.8 to the cutoff, opening the filter (making it clear).
 shake: shaking the unit increases the distortion mix.
